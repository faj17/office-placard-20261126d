A museum-placard-style one-line entry for an office artifact — the stapler. The program writes a single 157-character line to `/output/entry.txt`, with no trailing newline.

## Run

```sh
python3 main.py
```

## Entry

> Stapler, c. 1998. Steel and spring. A ritual press that wed two sheets with a single tooth; gift of the filing clerks, who believed no page should die alone.
